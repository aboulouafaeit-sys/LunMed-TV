## سياسة الخصوصية باللغة العربية (Privacy Overview)

يلتزم مشروع **LUNMED TV** بأعلى معايير حماية الخصوصية الرقمية لمستخدمي أجهزة التلفاز:
- **صفر جمع بيانات (Zero Data Collection):** لا نقوم بجمع أو حفظ أو معالجة أو إرسال أي بيانات شخصية، أو استعلامات بحث، أو سجلات مشاهدة، أو معلومات حسابات إلى أي خوادم سحابية.
- **صفر تتبع أو إعلانات (Zero Trackers & Ads):** التطبيق خالٍ تماماً من حزم SDK الإعلانية أو أدوات التحليلات التجسسية (خالٍ من Firebase Analytics, Facebook SDK, Crashlytics trackers, etc.).
- **معالجة محلية 100%:** جميع الإعدادات، والمفضلة، وبيانات التشخيص للأجهزة (الذاكرة والمعالج ودقة الشاشة) تتم معالجتها وحفظها محلياً فقط على رقاقة التخزين الداخلية للجهاز.
- **يعمل بدون إنترنت (100% Offline Capable):** التطبيق لا يتطلب اتصالاً بالإنترنت لتشغيل وظائفه الأساسية، ويعمل بكفاءة كاملة في البيئات المنعزلة عن الشبكة.

## 1. Information We Do NOT Collect

LUNMED TV is engineered under a strict **Zero-Knowledge, Zero-Telemetry** architecture. We do NOT collect:
- **Personal Identifiable Information (PII):** No names, email addresses, phone numbers, or account credentials.
- **Device Identifiers:** No Android Advertising ID (AAID), IMEI, MAC address, serial numbers, or hardware fingerprints are transmitted.
- **Usage Statistics & Telemetry:** No event logs, session lengths, button click sequences, or screen transition histories.
- **Media Playback History:** No tracking of apps launched, viewing habits, playlists, or stream durations.
- **Location Data:** No GPS, cellular, or Wi-Fi triangulation location data is ever accessed or stored.

---

## 2. On-Device Local Data Storage

All operational data generated by LUNMED TV is strictly confined to the local Android application sandbox:

1. **User Preferences (`Jetpack DataStore`):**
   - Theme configuration, palette choice, wallpaper profile, and app presentation mode (`SQUARE_IOS`, `COMPACT_CAPSULE`, `CINEMA_BANNER`).
   - Stored in private app storage (`/data/data/com.lunmed.tv/files/datastore/`).
2. **App Favorites & Category Index (`Room Database`):**
   - Pinned favorite apps and custom category assignments.
   - Stored in a local SQLite database (`/data/data/com.lunmed.tv/databases/`).
3. **Application Artwork Cache (`AppArtworkCache`):**
   - In-memory `LruCache` and local disk cache of installed application icons to enable 60 FPS remote navigation.
   - Cleared automatically upon system memory trim events (`onTrimMemory`) or manually via the Device Center Cockpit.

## 3. Permissions Requested & Justification

LUNMED TV requests only the minimal permissions required to function as an Android TV Home Launcher:

| Permission | Purpose & Scope | Network Transmission |
| :--- | :--- | :--- |
| `QUERY_ALL_PACKAGES` | Enumerate installed applications to display them in the launcher grid. | **None.** Local `PackageManager` only. |
| `RECEIVE_BOOT_COMPLETED` | Launch LUNMED TV immediately upon device power-on or restart. | **None.** Local system broadcast. |
| `ACCESS_NETWORK_STATE` / `ACCESS_WIFI_STATE` | Read local link speed, Wi-Fi RSSI dBm, and connection type for the Device Center cockpit HUD. | **None.** No network packets sent. |
| `LunmedHomeWatchdogService` (`AccessibilityService`) | Intercept `KEYCODE_HOME` on low-cost TV boxes where OEM launchers aggressively override user defaults. | **None.** Processes key events in local memory; no keystrokes are recorded. |
| Superuser (`su`) *(Optional)* | Execute `pm set-home-activity` on rooted Android TV boxes when the user explicitly requests it. | **None.** Local root shell execution. |

## 4. Third-Party Libraries & External Links

LUNMED TV contains **zero commercial advertising frameworks** and **zero external tracking analytics**. 

External links within the application (e.g., repository documentation links or system settings shortcuts) open directly via standard Android Intents. We encourage users to review the privacy policies of any third-party streaming applications launched via LUNMED TV.

## 5. Children's Privacy (COPPA Compliance)

LUNMED TV does not solicit or collect data from any user, including children under the age of 13. The launcher is safe for family, classroom, and enterprise television use.

## 6. Verification & Auditability

Because LUNMED TV is open source, our privacy assertions can be independently verified by inspecting the codebase:
- Absence of network tracking libraries in `build.gradle.kts`.
- Absence of background HTTP upload tasks or telemetry worker services.
- Clean execution passes in all automated unit tests.
